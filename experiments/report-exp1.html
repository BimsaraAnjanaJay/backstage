GET /validate (auth-service) and GET /products (product-service) are called exclusively by gateway-service — 100% peer-service calls, correctly flagged for relocation. Internal spans (auth-validate-endpoint, product-list-endpoints, etc.) are called only within their own service and are correctly retained. GET /api/checkout (gateway-service) is 100% external but from an anonymous client — not a peer — so the analyzer correctly routes it to review rather than relocate.

Figure 4 — Average Span Latency: Internal vs. Cross-service Calls

Average span duration (ms) for each function, split by whether the call was internal (same service) or cross-service. GET /api/checkout shows high cross-service latency (≈187 ms) because it orchestrates calls to both auth and product services. The misplaced functions (GET /validate, GET /products) show non-trivial cross-service latency (≈20 ms and ≈54 ms respectively), which compounds at scale.

RQ3 — Threshold Sensitivity Analysis

Figure 7 — Precision & Recall vs. Detection Threshold

Precision and Recall for Experiment 1 across thresholds 40%–95%. Both metrics remain constant at 100%, confirming the analyzer is threshold-robust for this scenario: all misplaced functions exhibit unambiguously high (100%) external call ratios.

Figure 8 — F1 Score vs. Detection Threshold

F1 = 100% across the entire swept range. The vertical dashed line marks the plugin default (65%). The flatness of this curve formally justifies the default: it is not a specially tuned optimum, but any reasonable value yields perfect accuracy on clearly misplaced functions.

Key Findings — Experiment 1

  • RQ1: Precision = Recall = F1 = 100% across 9 labelled functions. No false positives or false negatives.
  • RQ1: Two correctly identified misplaced functions — GET /validate (auth-service) and GET /products (product-service) — both recommended for relocation to gateway-service.
  • RQ1: Entry-point GET /api/checkout (gateway-service) is 100% externally called but correctly routed to review (not relocate) because the caller is anonymous, not a named peer service.
  • RQ2: Both misplaced functions are detected at the minimum sample size of N = 5 traces. Detection is stable across all volume levels up to 689 traces.
  • RQ3: Performance is constant across all thresholds 40%–95%. The default 65% threshold is validated as conservative and robust.
